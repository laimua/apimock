# Design: 亮/暗模式主题切换

Generated by /office-hours on 2026-05-23
Engineering review passed on 2026-05-23

## Problem Statement

项目已有 646 个 `dark:` Tailwind class 写好在代码里，但缺少运行时切换机制。当前 `globals.css` 使用 CSS 原生 `@media (prefers-color-scheme: dark)` 方式，只能跟随操作系统，用户无法手动切换。需要安装 `next-themes`、修改 CSS 配置、添加切换按钮，激活暗色模式。

## Constraints

- Next.js 16 (App Router) + React 19
- Tailwind CSS v4（不再是 tailwind.config.js，配置在 globals.css）
- 已有 lucide-react 图标库
- 切换按钮放在 GlobalHeader（已存在）
- 默认跟随系统，用户可手动覆盖

## Premises

1. 已有 646 个 `dark:` class 需要审计质量（颜色一致性、缺失配对）—— 先激活再边看边修
2. `@media (prefers-color-scheme: dark)` 需替换为 `next-themes` 的 `data-theme` 属性方式
3. 切换按钮放在 GlobalHeader 右侧，太阳/月亮图标 + 过渡动画
4. 默认跟随系统，手动可覆盖，localStorage 持久化

## Approach: 完整方案（B）

改动文件（5 个）：
1. `package.json` — 安装 `next-themes`
2. `src/app/globals.css` — 替换 `@media (prefers-color-scheme)` 为 `@custom-variant dark` + 属性选择器 + transition 配置
3. `src/app/layout.tsx` — 添加 ThemeProvider 包裹 + `suppressHydrationWarning`
4. `src/components/layout/GlobalHeader.tsx` — 桌面端 + 移动端引入 ThemeToggle 按钮
5. `src/components/ThemeToggle.tsx` — 新建切换按钮组件（太阳/月亮图标 + 过渡动画 + mounted 防闪烁）

### Step 1: 安装依赖

```bash
pnpm add next-themes
```

### Step 2: 修改 globals.css

```css
@import "tailwindcss";

/* Tailwind v4: 告诉 dark: class 何时生效 */
@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));

:root {
  --background: #ffffff;
  --foreground: #171717;
}

/* 替换 @media (prefers-color-scheme: dark) 为属性选择器 */
:root[data-theme="dark"] {
  --background: #0a0a0a;
  --foreground: #ededed;
}

/* 全局颜色过渡动画 */
* {
  transition-property: background-color, border-color, color;
  transition-duration: 200ms;
  transition-timing-function: ease-in-out;
}

@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --font-sans: var(--font-geist-sans);
  --font-mono: var(--font-geist-mono);
}

body {
  background: var(--background);
  color: var(--foreground);
}
```

### Step 3: 修改 layout.tsx

```tsx
import { ThemeProvider } from 'next-themes'

<html lang="zh-CN" suppressHydrationWarning>
  <body>
    <ThemeProvider attribute="data-theme" enableSystem defaultTheme="system">
      <GlobalHeader />
      <ToastProvider>{children}</ToastProvider>
    </ThemeProvider>
  </body>
</html>
```

关键 props：
- `attribute="data-theme"` — 匹配 globals.css 的 `[data-theme=dark]` 选择器
- `enableSystem` — 跟随系统偏好
- `defaultTheme="system"` — 默认跟随系统
- **ToastProvider 保留**：在 ThemeProvider 内部，包裹 children

### Step 4: 新建 ThemeToggle.tsx

```tsx
'use client'
import { useTheme } from 'next-themes'
import { useEffect, useState } from 'react'
import { Sun, Moon } from 'lucide-react'

export default function ThemeToggle() {
  const [mounted, setMounted] = useState(false)
  const { setTheme, resolvedTheme } = useTheme()

  useEffect(() => { setMounted(true) }, [])

  if (!mounted) {
    return <div className="w-9 h-9" />
  }

  return (
    <button
      onClick={() => setTheme(resolvedTheme === 'dark' ? 'light' : 'dark')}
      className="p-2 rounded-full hover:bg-gray-100 dark:hover:bg-gray-800 transition-colors"
      aria-label={resolvedTheme === 'dark' ? '切换到浅色模式' : '切换到暗色模式'}
    >
      {resolvedTheme === 'dark'
        ? <Sun className="h-5 w-5 text-yellow-500" />
        : <Moon className="h-5 w-5 text-gray-700" />
      }
    </button>
  )
}
```
